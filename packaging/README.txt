QLRust — 按空格预览（Rust 重写的 QuickLook）
================================================

一个常驻托盘的轻量预览工具：在资源管理器里选中文件，按一下空格，弹窗直接看内容；
再按空格（或 Esc）收起。焦点始终留在资源管理器，不打断你的操作。

内置支持四类格式：
  · 图片    png jpg jpeg gif bmp webp tif tiff ico cur …（默认按原图 50% 开窗，滚轮缩放）
  · PDF     pdf（顶栏页码框可点开输入页码直接跳；页缓存：翻回去秒开、顺带预取前后各一页；滚轮上下滑动/到边翻页 / 左键拖动移动窗口）
  · 文本    txt log ini cfg csv（每行左侧带行号，自动折行，默认 880 px 阅读宽度）
  · 源码    rs go py js ts c cpp java cs php rb lua sh ps1 sql json toml yaml …（仿 VSCode：等宽 + 行号 + 语法着色）
  · Markdown md markdown（标题/代码块/引用/列表/任务框/表格带排版，行内标记渲染后去掉，左侧可点目录）

Office（docx/xlsx/pptx/odt…）优先交给 Windows 自己的预览处理器渲染真排版（装了 Office 才生效）；压缩包（zip/cbz/jar）由随包附带的 qlr_plugin_office 画目录树，见第 5 节。


1. 怎么开始用
-------------
   双击 qlrust.exe                → 托盘出现图标，程序在后台待命
   在资源管理器里选中一个文件
   按空格                         → 出预览；再按空格收起

第一次运行时 Windows 可能弹"是否允许联网/防火墙"——QLRust 不联网，
可以直接取消/拒绝，不影响任何功能。


2. 目录里都是什么
-----------------
   qlrust.exe                  主程序（约 1.8 MB）
   pdfium.dll                  PDF 渲染引擎，运行时才加载；删了只是不能看 PDF
   plugins\                    插件目录，缺了也不影响四类内置格式
     qlr_plugin_demo.dll        示例插件：给视频扩展名画一张占位图
qlr_plugin_office.dll      Office 兜底（大纲卡片）与压缩包目录树
   portable.lock               有这个文件 = 便携模式（见第 4 节）
   UserData\                   便携模式下的配置与日志（首次运行后出现）
   README.txt                  本文件


3. 常用操作
-----------
   空格             打开 / 收起预览（顶栏「锁」开了之后空格与 Esc 都关不掉，且不能取消）
   Esc              收起
   左键拖动         所有格式：整个窗口跟着鼠标移动（不重绘、不频闪）
   拖窗口边/角      改窗口大小（四边与四角 6 px 热区，指针变成 ↔ ↕ ⤡；松手按新尺寸重渲染，
                     文本/Markdown 会按新宽度重新折行）
   右键上下拖动     图片/PDF：缩放，往上拖放大、往下拖缩小（每 60 px 一档 1.25×，
                    拖动时先缩放窗口、松手才重渲染）；文本/Markdown：按行滚动
   滚轮             文本：上下滚动；PDF：上下滑动（滑到页底继续滚 = 翻页）；
                    图片：放得下时缩放，放大后上下滑动
   按住 Shift 移动   放大镜：光标处出现 220x220 的镜头（默认 3 倍），松开消失
   Shift + 滚轮     调放大镜倍数 1.5x - 8x
   PageDown/PageUp  文本：翻一屏；PDF：翻页
   方向键           图片/PDF：上下左右微调
   顶栏（所有格式）  黑底：左边文件名；PDF 中间是页码框（点击后输入页码 + Enter 跳转，
                    Esc 取消）；页码框右边依次是 锁 / ↗ / ×：锁=阻止关闭（单向，开了不能取消）、
                     ↗=用系统默认程序打开这个文件、×=关闭预览；拖顶栏空白处也能移动窗口
   右侧滚动条       文本/源码按行、PDF 按页；点轨道跳、拖滑块滚
   跟随选中项       预览开着时在资源管理器换选文件，窗口 400 ms 内自动跟着换
   不支持的文件     不弹窗口也不画占位文字，只响一声系统提示音（已显示的预览会收起）
   投机预渲染       窗口收着时先把选中的那一个文件画好，按空格直接上屏；
                    设置 → 性能 → 投机预渲染，三档：关 / 自适应（默认）/ 总是
   托盘图标右键     设置…、关于、退出

   上面这些按键全都能改：托盘右键 →「设置…」（或 qlrust.exe --settings），
   点一行 → 直接按新键 → Enter 保存（Esc 取消、Backspace 恢复默认），改完立即生效。

配置文件是 UserData\config.json（便携模式）或
%LOCALAPPDATA%\QLRust\config.json（安装模式），字段都有注释。


4. 便携模式
-----------
目录里有 portable.lock 时，配置和日志都读写本目录的 UserData\，不碰系统目录，
U 盘里拷走就能用（换个账号也能跑）。删掉 portable.lock 就变回"用户目录"模式。

（便携模式对安装位置有要求：如果程序放在权限受限的目录里，日志可能写不进去，
此时日志里会有提示，功能不受影响。）


5. 插件：给别的格式加预览
-------------------------
把插件 DLL 放进 plugins\ 目录，重启 QLRust 就生效。插件只能接管"内置四类之外"
的扩展名（不会抢 .png/.pdf/.txt/.md）。写插件的方法见仓库 docs\dev\PLUGINS.md，
最小示例就是 plugins\qlr_plugin_demo.dll 的源码。

注意：插件和主程序跑在同一个进程里、以你的账号权限运行。
**只放你信任的插件。**


6. 卸载
-------
用安装脚本装的话：设置 → 应用 → QLRust → 卸载（或运行安装目录里的 uninstall.ps1）。
便携版：直接删目录；若曾注册过文件关联，运行一次 uninstall.ps1 可把注册表项清干净。

安装脚本（免管理员，全部写 HKCU 和用户目录）：
   pwsh -NoProfile -File scripts\install.ps1
   pwsh -NoProfile -File scripts\install.ps1 -Autostart       额外开机自启
   pwsh -NoProfile -File scripts\install.ps1 -NoAssoc         不注册文件关联


7. 出问题怎么办
---------------
日志（最有用的东西）：
   便携模式    <本目录>\UserData\logs\app.log
   安装模式    %LOCALAPPDATA%\QLRust\logs\app.log
   （日志按大小滚动，保留最近几份 app.log.1 …）

常见情况：
   · 按空格没反应
     1) 托盘里有没有图标？没有就是进程没起来，看日志开头。
     2) 焦点必须在资源管理器的文件列表上（点一下文件名再按）。
     3) 某些全屏独占程序（游戏、部分播放器）会吞掉空格；先切回桌面再试。
   · 托盘图标看不见
     可能被 Windows 折叠进"^"溢出区：任务栏设置 → 选择哪些图标显示在任务栏上。
   · PDF 打不开
     检查 pdfium.dll 是否和 qlrust.exe 在同一目录。
   · 想彻底重启
     托盘右键退出，或者命令行 qlrust.exe --quit。


8. 性能（本机实测，Win10 22H2 / i5-12400F / 16 GB）
---------------------------------------------------
   冷启动          50–85 ms（首次进程启动，含托盘与热键安装）
   按空格到出窗     1–3 ms（常驻态）
   4K JPEG         渲染 41 ms，峰值内存 12.5 MB
   48MP 图片        渲染 77 ms，峰值 12.5 MB
   26.6 MB 文本     21 ms（12 万行，只渲染可视区）
   200 页 PDF       翻页均值 6.3 ms
   空闲内存         7.6–8.8 MB

统计口径与复现方法见仓库 docs\dev\bench.md。


9. 许可与来源
-------------

（https://github.com/QL-Win/QuickLook，GPL-3.0）。PDF 渲染使用 PDFium
